# 3·4차시 퀴즈 생략 — 2026-09-18

## 확정 운영

- 1·2차시: 이론 → 퀴즈 → 영상 → 토론 → 중간 대시보드.
- 3·4차시: 이론 → 영상 → 토론 → 중간 대시보드.
- 4차시 이후 종합 대시보드. 3·4차시 퀴즈는 추가 수령 대상이 아니다.
- AI 검수는 사용자에게 승인 완료로 전달받았다. 영상 파일은 아직 미수령이다.
- 영상·토론은 원본 2~5번, 이론 자료와 기존 디자인은 유지한다.

## 적용 지점

- `src/contents/financial-course-data.js`: 차시별 `quizEnabled`.
- `src/contents/financial-course.js`: 이론 다음 단계, 단계 표시, 재접속 목적지, 저장된 3·4차시 step=2를 영상 step=3으로 복원. 내부 단계 ID 1~5와 videoId 0~3은 유지한다.
- `SlideViewer` / `QuizSync`: 강사가 마지막 이론 슬라이드에서 다음 단계 버튼을 누르면 1·2차시는 퀴즈, 3·4차시는 영상으로 함께 이동한다. 강사는 기존 플레이어, 학생은 기존 영상 안내 화면이다.
- `course-control.service.js`: 기존 소켓 이벤트명 `course:start-quiz` / `course:quiz`를 호환을 위해 유지하며 state.step은 1·2차시=2, 3·4차시=3이다. 중복 요청은 동일 commandId로 전달한다.
- `QuizPage`: 과거 주소나 북마크로 3·4차시 퀴즈 진입 시 영상으로 이동한다. 새 퀴즈 점수를 전송하지 않는다.
- `RoundIndicator` / 온보딩: 3·4차시는 4개 단계로 표시한다.
- `FinalResultPage`: 3·4차시는 ‘퀴즈 없음’으로 표시한다. 기존 DB 점수가 있더라도 정답률·정답 수를 산출하지 않는다. 기존 DB 컬럼은 보존한다.
- AI `app/financial_profile.py`: 차시별 순서 수정, 검수 대기 문구 제거. 금융 4축 분류·평가·질문 생성 기준은 유지한다.

## 검증 및 배포

- Node 자동 검증 10개, AI 자동 검증 31개 통과. AI 검증은 외부 제공자 대체 응답을 사용한 계약 검증이다.
- 변경 JSX/JS 린트, 웹 프로덕션 빌드 통과.
- 소켓 검증은 교사 1명·학생 20개 연결의 전체 차시 동기화, 재접속/지연 입장/재시도, 토론 미시작을 확인한다.
- 실제 브라우저에서 1~4차시 교사/학생 이동, 1·2차시 답안 재접속 유지, 3차시 오프라인 복귀, 3·4차시 과거 퀴즈 주소 및 늦은 입장, 단계 표시를 확인했다. 과거 퀴즈 주소 이동에서 발견한 상태 갱신 반복도 수정 후 재검증했다.
- 재현 스크립트: `output/playwright/verify-quiz-skip.js` (로컬 확인용). 완료 결과: `output/playwright/quiz-skip-verification.log`.
