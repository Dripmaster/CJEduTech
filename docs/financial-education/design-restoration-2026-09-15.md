# 기존 디자인 복원 — 2026-09-15

사용자 요청: 금융교육 기능은 유지하고, 요청하지 않은 화면 디자인 변경을 복원한다. 퀴즈는 전달받은 주황색 문제 카드 디자인과 승인된 진행 방식을 유지한다.

- 로그인: 원래 로봇과 Aigora 로고, 배경과 입력 카드를 사용한다.
- 시작: CJ 문구가 포함된 합성 배경 대신 기존 로봇·로고를 개별 배치한다.
- 안내: 기존 Onboarding 컴포넌트와 흰색 카드, 로봇, 주황색 버튼을 복원하고 본문만 금융교육으로 변경한다.
- 차시 안내: 기존 원형 STEP 디자인에 이론·퀴즈·영상·토론·중간 대시보드 5단계를 표시한다.
- 이론: 기존 PageHeader와 회색 배경/흰 카드로 원본 슬라이드를 표시한다. 학생 개별 슬라이드 이동 및 교사의 퀴즈 일괄 시작을 유지한다.
- 퀴즈: 문제 카드·보기·정답 선택 잠금·해설 공개·수동 페이지 이동·점수 저장을 유지한다.
- 영상: 기존 PageHeader·플레이어·하단 주황색 버튼 구성을 복원한다. URL 설정과 기존 진행 조건은 유지한다.
- 토론 및 대시보드: 기존 케이크·배지·아바타·레이아웃을 사용하고 금융이해/위험인식/계획성/실천의지 이름을 표시한다. 뚜레주르 상품명 문구는 제거한다.
- 종료: 기존 종료 이미지를 다시 사용한다.
