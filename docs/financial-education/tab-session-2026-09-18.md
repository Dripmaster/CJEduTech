# 탭별 접속 분리와 나가기 — 2026-09-18

교사·학생 화면에서 공유하던 localStorage와 로그인 쿠키 때문에 같은 브라우저의 다른 탭에서 역할·진행 정보와 API 인증 사용자가 달라질 수 있었다. 활성 수업 화면의 저장소를 sessionStorage로 통일하고, 로그인 시 탭 전용 토큰을 발급해 계정별 아바타와 퀴즈 저장에 사용한다. 이전 쿠키 방식 API는 호환성을 유지한다. 명시한 인증 토큰이 잘못됐을 때 다른 사용자 쿠키로 대체하지 않는다.

기존 닉네임·아바타와 디자인을 유지한다. 공통 헤더, 아바타 선택, 토론 진행, 종료 화면에 ‘나가기’를 추가했다. 이 버튼은 현재 탭의 연결·저장 정보만 정리하고 학생 재접속 링크만 있는 종료 화면으로 이동한다. 다른 탭이나 DB 기록은 지우지 않는다. 교사의 종합 결과 화면은 기존 공용 경로를 계속 사용할 수 있다.

새로고침 시 계정과 차시/단계를 유지한다. 미제출 퀴즈 선택이나 슬라이드 내부 페이지의 복구를 새로 구현한 것은 아니다. 다시 로그인하면 현재 교사의 퀴즈/영상 전환 상태를 적용한다. 교사가 수업 전체를 처음부터 시작하려면 운영자 서버 초기화가 별도로 필요하다.

마지막 소켓 접속자가 나가면 진행 중인 토론 기록을 지우던 동작도 수정했다. 빈 방에서는 AI 독려를 실행하지 않고 발언·주제를 보관해 재접속할 수 있다. 이는 서버 프로세스 안의 보관이며, 운영 서버 재시작 전에 교사가 토론 종료를 통해 결과를 저장해야 한다. 자동 종료 타이머 정책은 변경하지 않았다.

## 검증

- Node 테스트 15개: 기존 4차시 흐름·퀴즈 저장·20명 단계 동기화, 명시한 인증 토큰 우선/잘못된 토큰 거부/이전 쿠키 호환, 마지막 접속자 이탈 후 토론 발언 보존.
- 인증 계정 혼선과 마지막 이탈 기록 유실을 수정 전 실패로 재현한 뒤 수정 후 통과 확인.
- 같은 브라우저의 교사 1개·학생 2개 탭으로 실제 UI 실행. 실제 HTTP/Socket.IO/인증 코드를 사용하며 SQL 경계만 로컬 메모리로 대체했다. 운영 DB E2E와 구분한다.
- 학생별 계정·아바타·점수 분리, 새로고침 후 계정·2차시 유지, 한 탭 나가기 후 다른 탭 유지, 재로그인 후 점수 유지, 다른 계정 재로그인 동기화, 교사 종합 결과 진입, 교사용 깊은 경로와 ?admin=1을 통한 학생의 교사 화면 진입 차단 확인.
- 빌드 및 신규 핵심 모듈 lint 통과. 전체 레거시 lint가 모두 정리됐다는 뜻은 아니다.
- 코드 리뷰에서 발견한 교사 공용 결과 경로·동기화 참조·역할 전환 잔여 상태 문제를 수정하고 브라우저로 재확인했다.

## 운영 적용

Node 수정 파일: `server/middlewares/auth.js`, `server/routes/auth.routes.js`, `server/services/socket.service.js`.
기존 웹의 쿠키 인증도 유지하므로 Node를 먼저 적용하고 웹을 Vercel로 배포한다.
Node 변경 전 백업: `/var/backups/financial-education/tab-session-20260918-wfg0fibf`.

최초 배포 후 기존 localStorage의 접속 기록은 읽어오지 않으므로 새로 로그인한다. 이후 테스트는 같은 브라우저의 별도 탭으로 진행할 수 있다. 테스트 후 각 탭에서 ‘나가기’를 누른다. ‘나가기’는 수업 전체 초기화가 아니다.

## 교사 접근 제한 추가

학생 화면과 종료 화면에 교사용 접속 링크를 노출하지 않는다. 교사용 주소에 접속해도 비밀번호 인증을 통과해야 수업 화면에 들어갈 수 있다. 비밀번호 해시는 서버 환경에만 저장하고 평문 접속 정보는 운영자의 로컬 권한 0600 파일로 별도 전달한다. 웹 소스·문서·학생 안내에 비밀번호를 넣지 않는다.

서버가 서명한 교사 토큰의 role과 만료를 검사한다. 화면의 isAdmin 값이나 URL의 admin 쿼리로 교사 권한을 부여하지 않는다. 퀴즈 단계 시작, 토론 설정·주제 이동·종료·AI 참여 안내 요청은 서버에서도 교사만 실행할 수 있다. 학생은 다른 사람의 개인 최종 결과 생성/조회나 강제 재생성을 요청할 수 없다. 공통 토론 총평은 인증한 참여자가 기존대로 조회한다.

교사 비밀번호 인증 토큰은 12시간 유효하며 탭별로 저장된다. 교사도 나가면 다시 인증한다. 학생 재접속 흐름에는 교사 진입 방법을 표시하지 않는다.
