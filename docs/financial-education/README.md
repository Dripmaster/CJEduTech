# 금융교육 구현 상태와 실행

기준: 2026-09-15, `codex/financial-education`. 기존 CJ main과 운영 서버에 적용하지 않은 개발본이다.

## AI 현재 범위

9월 20일 수업에 맞춰 추가 교재 검색 기능을 제거했다. 차시별 고정 자료·시나리오와 금융 4축 프롬프트를 사용한다. 원본 보충 교재는 보관하며 검색/자동 주입하지 않는다. 제거 후 AI 테스트 30개 통과. 실제 모델 호출은 앞선 점검에서 크레딧 소진으로 실패하여 복구 후 정상 호출 검증이 필요하다.

## 이번 구현

- 이론→퀴즈→영상→토론→기존 중간 결과를 4회 진행한 뒤 기존 종합 결과로 연결. 게임·기존 CJ 교육 안내 경로 제외.
- PDF를 1920px JPEG로 렌더링한 원본 슬라이드 뷰어. 1차시 도입 1~4쪽 포함, 이론에서는 퀴즈 9·12·26·37쪽 분리. 활동 페이지는 원본 순서대로 유지.
- 수령된 퀴즈 4페이지·8질문의 화면 구현. 선택형 7문항만 점수 대상, 설명형 1문항은 해설만 표시. 3·4차시는 준비 중으로 표시하며 점수를 만들지 않음.
- 퀴즈는 선택 후 별도 `정답·해설 보기` 버튼으로 확인한다. 이 진행 방식은 09-15 사용자 확정 사항이다. 강사는 해설을 바로 열고 다음 단계로 이동할 수 있으며 학생 점수를 쓰지 않는다.
- 퀴즈 점수 route/service/repository/schema가 4차시 지원. 실제 DB 스키마는 아직 적용하지 않았다.
- 금융이해·위험인식·계획성·실천의지 라벨과 결과 차트 배지를 변경. 기존 음식·아바타 등 재사용 여부 미확정인 에셋은 보존.
- 시나리오 1~4와 토론 주제 12개를 Node·AI에 같은 키/순서로 반영. 안내 화면에는 원본 활동 1·2·3의 세부 문구도 표시하되 조별/짝 발표 지시는 확정된 개인 참여 방식에 맞췄다. 원본 이론 슬라이드는 변경하지 않았다. 종합 결과는 영상 인덱스 0~3 집계. 아카이브 차시 번호 누락도 수정.
- 채팅 최근 표시 100개 제한과 전체 결과 기록을 분리해 101개 이상 발언도 초반 참여자·공감·분류가 집계/아카이브에 남게 수정.
- 결과 조회 실패 시 임의의 점수·랭킹·총평 생성 제거. API 점수 열을 실제 결과로 변환. 미수령/미응답은 0점으로 만들지 않음. 고정 완수율 100%를 실제 차시별 퀴즈 기록으로 교체. 교사 선택 학생의 퀴즈 점수는 기존 API가 지원하지 않아 학생 본인 화면에서 조회하도록 안내.
- Node AI 주소·CORS 설정을 환경변수로 분리. AI의 1점이 100%로 변환되던 경계 수정. 실제 사용자·차시·주제 맥락 전달.
- 이론은 학생도 개별 슬라이드를 본다. 교사가 퀴즈를 시작하면 학생 전체가 해당 차시 퀴즈로 이동하도록 반영했다. 다른 단계 전체 동기화나 새 교사 인증 체계는 추가하지 않았다. 토론 주제·종료는 기존 Socket.IO 강사 제어를 활용한다.

## 로컬 실행

웹 저장소에서 `npm ci`, `npm run dev -- --host 127.0.0.1 --port 5178`. 강사 진입 `/admin/session`, 학생 진입 `/`. 현재 준비 상태에서는 API 없이 슬라이드/강사 퀴즈/영상 준비 화면을 확인할 수 있다.

로컬에서 API까지 연결할 때는 웹 `.env.local`에 아래 값을 설정하고 Vite를 재시작한다. 이 파일은 배포 빌드에 가져가지 않는다.

```dotenv
VITE_API_URL=http://127.0.0.1:3100
VITE_SOCKET_URL=http://127.0.0.1:3100
```

Node의 로컬 환경은 `deploy/financial-education/node.env.example`을 기준으로 `NODE_ENV=development`, `CORS_ORIGINS=http://127.0.0.1:5178`을 사용한다. 브라우저도 `localhost` 대신 `127.0.0.1`로 통일한다. DB 접속정보는 새 교육용 DB의 실제 값으로 설정한다. 운영 `web.env.example`의 빈 주소는 Nginx로 웹·API를 같은 출처에 서비스할 때의 값이다.

`npm run build` 출력은 `dist-financial/`이다. 기존 root 소유 `dist/` 및 `.vite-temp`를 건드리지 않도록 Vite config runner와 별도 출력 경로를 사용한다.

Node는 `server`에서 `npm ci`, 별도 교육용 환경변수 설정 후 `npm start`. 기존 CJ DB에 연결하지 않는다. `server/db/schema.sql`은 **새 빈 교육용 DB**를 위한 스키마다. 이미 존재하는 테이블에는 `IF NOT EXISTS` 때문에 4차시 열이 자동 추가되지 않는다.

AI 저장소는 Python 3.12 가상환경에 `requirements-financial.lock.txt` 설치 후 `uvicorn app.main:app --host 127.0.0.1 --port 8100`. 금융교육 실행 경로는 기존 KoNLPy/Word2Vec 분류기를 사용하지 않는다. 예전 파일은 보존되어 있지만 main 및 개인 총평에서 import하지 않는다. GPT 분류와 실패 상태를 사용하며 API 응답의 `cj_values` 등 기존 필드명은 호환 목적으로 유지했다. 세부 4축 정의는 홍선생님 검수 전 초안이다.

## 검증 명령과 범위

- `npm test`: 차시·자료 분리·저장 계약 + 실제 Node 서버/Socket.IO의 4개 방 종료·아카이브·AI 점수 변환 테스트. 임시 아카이브와 가짜 AI HTTP 서버를 사용하고 실제 MySQL/OpenAI는 호출하지 않는다.
- 신규 금융교육 UI 파일의 ESLint, 전체 웹 빌드.
- AI 가상환경에서 `python -m unittest discover -s tests -p 'test_financial*.py'`: 정규화·실패 처리·FastAPI 질문/분류/총평 계약. OpenAI 경계만 대체한다.
- 브라우저: 원본 슬라이드 수동 전환, 1차시 마지막→퀴즈, 선택·해설, 설명형 문항, 퀴즈→영상 준비→토론 주제 안내 화면 확인.

실제 MySQL 저장/재시작, 실제 모델 평가 품질, 20명 동시 수업, 수령 영상 재생·배포 환경은 아직 검증하지 않았다. 기존 전체 린트 기준선 오류는 이번 변경과 구분한다.

## 배포 선택

**기존 EC2를 활용한 교육용 분리 배포를 우선안으로 준비했다.** Nginx가 프런트 `dist-financial`과 API·Socket.IO를 같은 출처로 서비스하고, 교육용 Node(3100)·AI(8100)·DB·아카이브를 기존 CJ와 분리한다. `deploy/financial-education/`의 Node/AI 환경 파일과 systemd, Nginx 설정은 설치 전 검토할 예시이며 서버에 적용하지 않았다. 도메인, 인증서, 서비스 사용자·실제 Node/Python 경로, 새 DB/계정과 비밀값을 확정해야 한다.

프런트를 기존 방식처럼 Vercel에 유지하는 것도 가능하다. 그 경우 Vercel 프로젝트/배포 브랜치/Output Directory=`dist-financial`을 확인하고 VITE_API_URL·VITE_SOCKET_URL·CORS를 새 교육용 API 주소에 맞춘다. 과거 Vercel 프로젝트에 그대로 push하면 의도하지 않은 자동 배포가 될 수 있으므로 이번에는 push하지 않았다.

영상은 우선 수령 파일을 적용·측정한 뒤 필요하면 S3 저장 + CloudFront 전송으로 분리한다. 공식 구성 참고: https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/on-demand-streaming-video.html
