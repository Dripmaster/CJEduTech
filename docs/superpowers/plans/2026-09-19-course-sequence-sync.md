# 금융교육 차시 재배치·슬라이드 동기화 구현 계획

Goal: 합의한 1차시 무토론, 2차시 저축, 3차시 보험·노후, 4차시 투자 흐름과 교사 슬라이드 동기화.
승인 근거: 현재 대화의 명시적인 구현 요청과 기존 차시 합의. 현재 금융교육 브랜치 및 미커밋 복원 작업을 유지한다.

Architecture: 화면의 차시와 영상 활동 ID를 분리한다. 기존 영상 ID/키는 그대로 유지해 영상 URL과 결과 파일의 의미를 바꾸지 않는다. 토론 저장 방은 영상 활동별로 분리하고 차시 메타데이터는 실제 수업 차시로 기록한다. 3차시는 두 활동 후 기존 중간 대시보드 형식으로 합산한다. 슬라이드 상태는 전용 수업 소켓의 교사 명령으로 갱신하며 재접속 시 현재 상태를 반환한다.

- [x] 수업 모델/진행: financial-course-data.js, financial-course.js, RoundStepContext. 빈 활동과 차시 내 다음 활동, 저장 상태 복원 테스트.
- [x] 토론/결과: 영상·토론 페이지, ChatHistory/Input/Overview, 중간·최종 결과. 기존 ID 유지, 3차시 두 활동 분리 저장/합산, 최종 총평 트리거를 투자 종료로 수정. Socket.IO·집계 테스트.
- [x] 슬라이드: course-control.service와 QuizSync, SlideViewer. 교사 권한·원본 페이지 유효성 검증, 20명 전달, 접속 복구, 학생 변경 차단. 퀴즈 전환 이후 늦은 슬라이드 명령 차단.
- [x] AI 연결: educational_content의 lesson_id를 2/3/4/3으로 변경하고 수업 안내 프롬프트 정정. 영상 ID 불변 및 이론 자료 조회 검증.
- [x] 기존 테스트/빌드 및 교사·학생 실제 브라우저 확인. 피드백 대응표에 로컬 수정과 배포 상태, 미해결 품질 문제를 구분해 기록.

검증 데이터는 가상 학생과 로컬 서버를 사용한다. 영상 미수령 상태는 표시를 유지하고 운영 데이터 초기화·배포는 이번 요청에 포함하지 않는다. 원본 슬라이드 이미지 및 승인된 디자인/5초 결과 연출은 변경하지 않는다.
